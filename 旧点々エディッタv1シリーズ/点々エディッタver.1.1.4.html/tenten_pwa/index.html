📲 アプリとしてインストールする方法

iPhone / iPad (Safari)

  1. Safariでこのページを開く
  2. 下部の「共有」ボタン（□↑）をタップ
  3. 「ホーム画面に追加」を選択
  4. 「追加」をタップ → アプリとして起動可能に！

Mac (Chrome / Edge)

  1. アドレスバー右側のインストールアイコン（⊕）をクリック
  2. または メニュー → 「アプリをインストール」

Windows (Chrome / Edge)

  1. アドレスバー右のインストールボタンをクリック
  2. 「インストール」を選択

✨ 高画質化機能の使い方

  1. 「ドットアート生成」タブで画像を生成する
  2. 「高画質化」タブに切り替える
  3. アップスケール・シャープネス・ノイズ除去を設定
  4. 「高画質化を実行」ボタンを押す
  5. 「高画質版を保存」で書き出し

💡 おすすめ設定：アップスケール2x ＋ Lanczos ＋ バイラテラルノイズ除去 ＋ シャープネス「中」

🎨 基本的な使い方

  • 画像はファイル選択・ドラッグ＆ドロップ・Ctrl+V貼り付けで読み込めます
  • 「超輪郭検知」が最もきれいに輪郭を検出します
  • 点の間隔を小さくするほど細密になりますが処理が重くなります
  • 型抜き機能で文字や画像の形に切り抜けます
  • データコピーでCSV形式（X,Y,文字,R,G,B）で書き出せます
